# 蓝子鱼形态参数智能测量与标注系统 V1.0 用户手册草稿

## 1. 软件用途

本软件用于蓝子鱼侧面照片的形态参数测量。系统可辅助完成图像校准、关键点定位、人工修正、几何测量和结果导出。

## 2. 图像要求

推荐使用满足以下条件的图片：

- 鱼体侧面平放，轮廓完整。
- 校准板或比例尺清晰可见。
- 尾鳍上下叶清楚可辨。
- 鱼体未严重弯曲、遮挡或反光。
- 图像清晰，无明显运动模糊。

如鱼鳍明显展开、尾鳍破损、反光严重或姿态异常，系统结果需要人工重点复核。

## 3. 单鱼测量流程

### Step 1 导入与自动测量

进入“单鱼测量”页面，上传一张鱼体照片，填写 `specimen_id` 和可选的 `weight_g`，然后点击“开始自动测量”。

正式 V1.0 单鱼测量页采用两张主卡片布局：Step 1 负责导入与自动测量，Step 2 负责复核、拖拽修正和导出。主要测量结果以指标卡片显示，完整字段表格放在折叠区中，便于普通用户查看和软著截图。

系统会在后台依次完成：

- 自动校准；
- 生成 `warped_image`；
- 鱼体识别与分割；
- 自动预标注；
- 形态测量；
- 生成正式测量点和测量表。

界面会显示“正在校准图像……”“正在识别鱼体……”“正在计算形态参数……”“测量完成。”等进度提示。校准仍然是硬门槛：如果校准失败，系统不会继续测量，也不会使用默认 `mm_per_pixel = 0.1`。

Step 1 中的“校准详情”默认收起。展开后可查看校准状态、检测到的 marker 数量、`mm_per_pixel`、原始图 marker overlay 和 `warped_image`。如果校准失败，可查看失败原因，并按提示重新拍摄或进入手动校准/高级工具检查。

`specimen_id` 用于区分个体、批次或复测记录；`weight_g` 为样品重量，单位为 g，支持小数。填写后的重量会随 CSV、Excel 和 JSON 一起导出，便于后续进行长度-重量关系、肥满度或生长记录分析。本系统当前不默认计算肥满度，需在明确长度口径和公式后再单独分析。

### Step 2 复核、修正与导出

如果 Step 1 尚未成功完成自动测量，Step 2 会提示“请先完成导入与自动测量。”

自动测量完成后，Step 2 显示正式测量图像、可拖拽测量点、`body_midline_axis`、体高线、尾柄高线、P7V 和测量结果表。用户可直接拖动点位，并点击组件内“应用修改”同步表格。

Step 2 中可以：

- 重置为自动测量结果；
- 保存人工确认结果；
- 导出当前结果 CSV；
- 导出当前结果 Excel；
- 导出标注预览图；
- 导出关键点 JSON。

正式前台中的修正默认保存在当前会话和下载文件中。点击“保存人工确认结果”时，只写入 `results/formal_v1_user_outputs/`，不会自动覆盖项目中的历史人工确认标签或 `corrected_keypoints`。

## 4. 批量测量流程

进入“批量测量”页面，上传多张图片，点击“批量运行校准和自动测量”。系统会生成每张图片的处理状态：

- `success`：处理成功；
- `calibration_failed`：校准失败；
- `needs_review`：需要人工复核；
- `exported`：已加入导出表。

批量结果可导出 CSV 或 Excel。

## 5. 结果导出

“结果导出”页面默认展示普通用户常用字段：

- 图片名称；
- 样本编号；
- 虚拟压拢尾鳍总长；
- 历史投影法总长；
- 标准长；
- 叉长；
- 体高；
- 头长；
- 吻长；
- 尾柄长；
- 尾柄高；
- 测量状态；
- 备注。

完整内部字段可通过“完整导出”下载。

## 6. 高级工具

高级工具页面用于开发者和高级复核，包括 Review Queue、Advanced overlay、模型评估结果和压拢尾鳍总长审计说明。普通用户无需进入该页面。

## 7. 注意事项

- 自动测量结果必须经过人工检查后再用于正式分析。
- 校准失败或图片质量差时，不建议直接使用测量结果。
- 虚拟压拢尾鳍总长目前是候选口径，与历史投影法总长并行保留。
- 本软件不会在普通前台中自动覆盖已有人工确认标注。
