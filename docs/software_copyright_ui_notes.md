# 蓝子鱼形态测量系统 V1.0 前台界面说明

本文档用于软件著作权材料整理和截图准备，说明 SiganusMorph Local 新增的正式前台界面。

## 软件名称

蓝子鱼形态参数智能测量与标注系统 V1.0

## 前台页面

系统新增以下普通用户入口：

- 首页：展示软件简介、主要功能、推荐流程和适用图像条件。
- 单鱼测量：按“导入与自动测量 → 复核、修正与导出”的两步流程完成单张图片测量。
- 批量测量：支持多张图片上传和批量状态汇总。
- 结果导出：展示简化测量表，并提供 CSV / Excel 导出。
- 高级工具：保留 Review Queue、Advanced overlay、模型评估和开发者复核入口。

## 推荐工作流

正式前台默认隐藏复杂调试设置，普通用户按以下流程操作：

1. 导入鱼体照片，填写 `specimen_id` 和 `weight_g`，点击“开始自动测量”。
2. 系统自动完成校准、生成 `warped_image`、鱼体识别、自动预标注和形态测量；校准失败时不会继续测量，也不会使用默认 `mm_per_pixel = 0.1`。
3. 展开“校准详情”时可查看校准状态、marker 数量、`mm_per_pixel`、原始图 marker overlay 和 `warped_image`。
4. 在 Step 2 复核正式测量图像、可拖拽测量点、`body_midline_axis`、体高线、尾柄高线和 P7V。
5. 必要时人工修正关键点，点击“应用修改”更新测量表。
6. 保存人工确认结果，或导出测量 CSV、Excel、标注预览图和关键点 JSON。

## 界面展示原则

- 使用中文界面。
- 不显示本地绝对路径。
- 默认不显示 heatmap 点、旧模型点、legacy axis 和开发调试图层。
- 异常姿态、尾鳍展开、遮挡、反光严重或校准失败时提示人工复核。
- 高级工具不会作为普通测量默认入口。

## 正式视觉系统

V1.0 前台采用统一的科研测量软件风格：浅灰白页面背景、白色内容卡片、深蓝主色、青蓝强调色、绿色成功状态、橙色警告状态和红色错误状态。首页、单鱼测量、批量测量、结果导出和高级工具均使用统一标题、卡片、状态 badge 和按钮样式，避免默认 Streamlit demo 风格。

## 算法说明边界

正式前台调用当前成熟测量流程，不训练新模型，不修改人工确认标签，不覆盖历史测量结果。

其中 `TL_compressed_virtual_mm` 是虚拟压拢尾鳍后的候选总长字段，在人工一致性验证完成前与历史投影法总长并行保留。
