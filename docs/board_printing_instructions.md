# 校准板打印说明

1. 使用 A3 横向纸张打印。
2. 打印比例选择实际大小 100%，不要选择适应纸张、缩放到页面或自动居中缩放。
3. 打印后用真实尺子检查 0-10 cm、0-30 cm 和 0-35 cm 刻度。
4. 四角 ArUco 标记应完整、清晰、无裁切。
5. 拍摄前保持校准板平整，避免翘曲造成透视误差。
6. 推荐先拍摄一张空板照片，用于检查 ArUco 检测、透视校正和比例换算。
7. V2 校准板请优先使用 `data/calibration_board/v2_charuco_plumb/siganusmorph_a3_v2_charuco_plumb_print.pdf`。
8. V2 板打印后，检查 0-35 cm 尺子、8 个 ArUco、ChArUco 面板和外框直线是否清晰。
9. V2 板软件主比例来自板面坐标；如果打印机缩放，所有测量都会随之偏移，所以必须确认 100% 实际大小。
