# SiganusMorph Local V1.0 正式界面样式指南

## 设计定位

正式前台用于普通用户测量、软件展示和软著截图。视觉参考 monopo saigon 的 editorial silence 原则，并针对科研测量软件做了克制调整：界面保持黑白灰、数据优先、状态明确，色彩只出现在首页媒体图和必要的成功、警告、错误状态中。

## 核心原则

1. 直角内容面：卡片、图像、输入框和表格均为 `0 px` 圆角。
2. 全圆角动作：按钮和状态标签使用完整 pill 轮廓。
3. 无阴影：层级通过留白、细边框和排版建立，不使用浮层阴影。
4. 单一彩色媒体：虹彩材质只用于首页 hero，不进入按钮、表单或数据卡片。
5. 科研状态优先：绿色、琥珀色和红色仅用于成功、需复核和失败状态。

## 颜色

- Obsidian / 主文字：`#000000`
- Inkstone / 次级标题：`#181818`
- Felt Gray / 辅助文字：`#6D6D6D`
- Hairline / 细边框：`#D8D8D4`
- Canvas / 页面背景：`#F5F5F3`
- Paper / 内容面：`#FFFFFF`
- Success / 成功：`#1F7A4D`
- Warning / 需复核：`#A86600`
- Error / 失败：`#B42318`

## 字体与排版

- 字体栈：Inter、系统字体、微软雅黑、苹方。
- 首页标题采用轻字重；普通工作页标题保持紧凑，不使用夸张展示字号。
- 页面最大宽度为 `1120 px`。
- 以 `4 px` 为基础节奏，常用间距为 `14 / 18 / 24 / 28 / 42 px`。
- 正文与说明文字保持正常字距，不使用负 letter-spacing。

## 组件

### Hero

- 首页使用 `assets/formal_ui/iridescent_hero.webp` 作为唯一彩色媒体。
- 其他页面使用白色编辑式页头和上下细边线。
- 首页图像上使用暗色遮罩保证中文标题对比度。

### 卡片与工作区

- 白底、`1 px` hairline、`0 px` 圆角、无阴影。
- 单鱼测量工作区、批量队列与导出区沿用同一容器语言。
- 指标卡片相互共用边线，减少卡片套卡片的视觉噪声。

### 按钮

- 主按钮：黑底白字、完整 pill。
- 次要按钮：透明底、黑色描边、完整 pill。
- hover 仅做轻微位移和黑白反转；不使用彩色渐变。
- 禁用按钮保持浅灰描边，避免被误认为可操作。

### 状态 Badge

- 普通信息使用灰色描边。
- 成功、需复核和失败使用语义色描边与文字，不使用大面积彩色底。

### 输入与上传

- 输入框、选择框和上传区域均为直角。
- 上传区使用灰色虚线边框；背景保持白色。
- 表单样式不改变原有校准、远程任务或导出逻辑。

## 页面结构

- 首页：虹彩 hero、三个主要入口、功能网格、五步工作流、适用图像条件。
- 单鱼测量：导入与自动测量、复核修正与导出。
- 批量测量：上传队列、远程处理状态、逐图复核与批量导出。
- 结果导出：结果源、简化表格、CSV/Excel 下载。
- 联系我们：维护信息、反馈要素和使用建议。

## 正式界面与管理工具

正式前台只显示首页、单鱼测量、批量测量、结果导出和联系我们。Review Queue、Advanced overlay 和开发工具继续保留在管理用途代码中，不进入公开导航，本次样式更新不修改其核心功能。
