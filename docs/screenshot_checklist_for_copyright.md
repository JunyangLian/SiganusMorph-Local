# 软件著作权截图清单

用于准备“蓝子鱼形态参数智能测量与标注系统 V1.0”软著说明书截图。

## 必选截图

- 首页：软件名称、简介、主要功能、推荐流程。
- 单鱼测量 Step 1：导入与自动测量卡片，包括上传、样本编号、重量、状态 badge 和开始自动测量按钮。
- 单鱼测量 Step 1 校准详情：展开后显示 marker 数量、比例尺和校正后图像。
- 单鱼测量 Step 2：左侧测量预览工作区，右侧测量指标卡片和操作按钮。
- 批量测量：多图上传和处理状态表。
- 结果导出：简化测量表和导出按钮。
- 高级工具：Review Queue / Advanced overlay 入口。

## 截图注意事项

- 截图中尽量使用中文界面。
- 首页和正式页面应呈现白色卡片、深蓝主按钮、状态 badge 和清晰两步流程。
- 不展示本地绝对路径。
- 不展示过多模型版本号或调试字段。
- 不展示含隐私信息的文件夹路径。
- 图像质量异常时，应保留“需要人工复核”的提示。
- 高级工具截图应强调其为开发者和高级复核入口。

## 推荐演示数据

建议使用一张轮廓清晰、校准板可见、尾鳍完整的蓝子鱼侧面照片进行演示。

如果需要展示质量控制功能，可另选一张尾鳍展开、姿态异常或校准失败的照片，展示系统复核提示。

## 不建议截图的内容

- 模型训练日志。
- 调试用 heatmap 点云。
- 本地绝对路径。
- 未经人工确认的训练标签导出。
- 历史实验中间结果目录。
