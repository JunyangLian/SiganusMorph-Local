# 拍照协议

1. 鱼头统一朝左。
2. 鱼体、尺子、ArUco 标记必须在同一平面。
3. 相机垂直向下拍摄，尽量减少透视畸变。
4. 光线均匀，避免强反光、阴影和局部过曝。
5. 尾鳍尽量自然展开，避免末端卷曲或被遮挡。
6. 吻端、眼睛、鳃盖后缘、尾鳍基部、尾鳍末端、臀鳍基部后端不能被遮挡。
7. 使用 A3 校准板时，打印必须选择实际大小 100%，不要缩放或适应纸张。
8. 打印后用真实尺子检查 0-10 cm 和 0-30 cm 是否准确。
9. 正式拍摄前先拍一张空板图，用于测试 ArUco 标记和比例尺识别。
10. 每张图尽量只放一条鱼，避免多条鱼相互遮挡。
11. 鱼体应尽量放在中央蓝色区域，避免压住四角 ArUco 标记。
12. 如果样本编号使用 1-40 编号区，请确认遮挡珠位置清晰可见，并在软件中同步选择编号。
